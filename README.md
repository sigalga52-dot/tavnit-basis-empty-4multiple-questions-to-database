תבנית גמישה ליצירת שאלון אמריקאי עם 4 תשובות, כשהתשובות אוטומטית נכנסות לשיט. כדי להכניס שאלות, תשובות ולקרוא בשם חדש, יש להעתיק הקוד לג'מיני ולהנחות אותו איך לשנות.  
למעלה מן הצורך - פירוט של איך להתאים שאלות ותשובות ספציפיות ואיך להעלות ליותר מ-4 שאלות נמצא בשולחן עבודה, תיקיית הוראה העשרה, במסמך "קישורים לאתרים, מצגות, כלים לבנית בוטים ועוד" תחת הכותרת "חידון 4 שאלות עם דאטהבייס לאיסוף תשובות התלמידים מוכן בשיטס" התבנית נוצרה על בסיס קוד של קנבה, והותאמה לגוגל ע"י ג'מיני. כדי להכניס שאלות ספציפיות - פירוט במסמך הנל.
